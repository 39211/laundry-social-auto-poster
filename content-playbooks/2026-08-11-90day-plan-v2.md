## 第三部分:內容怎麼做出來(v2 新增)

**圖片**:風格母版 v2(`data/style-master.md`)—— 你店的實景 DNA(粉紅切割墊、白溝槽牆、掛衣輸送架,背景錨按日輪替)+ 可見的相機行為(俯角 15 度、主體佔畫面 35–50%、窗光側打、背景可辨識)。物件材質配方見 `data/object-recipes.md`(8 大類)。**禁品牌標誌**。

**影片**:15 秒三幕(擔心 → 處理中 → 放心),船長工法:前 3 秒建規則/強好奇、鎖焦不漂移、接觸點與重量寫死、手部解剖正確、情緒寫進鏡頭而非貼標籤。

**文案**:職人口吻 → 主題句 → 判斷方法 → 誠實界線 → **參考價** → LINE ID → 互動問句 → hashtag。價格由 `withPriceLine` 依物件家族自動帶入,混合主題不塞價。

## 第七部分:防線清單(為什麼不會再斷)

1. **內容層**:計畫表指定物件 → 七天重複閘 → 文不配圖閘 → PNG 真偽閘 → day-lock 自癒(三條生成路徑全覆蓋)→ **審批指紋**(核准後被改寫拒發)
2. **排程層**:每日觸發不過期 → 30 分巡邏(救停用/救死觸發器/救發文/救 YT)→ 22:50 結算末班救援 → 維護令牌(人為暫停不被翻案)
3. **發布層**:單飛鎖(不可能重複貼文)→ live 限當日 → media_publish 送出後永不重試 → 媒體 URL 驗 content-type
4. **判斷層**:一律看發文紀錄,不信退出碼、不信自述
