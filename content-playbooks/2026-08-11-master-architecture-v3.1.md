## 訂單作業層(全新,第0層/01 致命修正)

```
渠道(帶碼) → /go/line.html?source=渠道碼 → LINE 對話(老闆) → 訂單
   ↑ GA4 自動記 line_click by source          ↓
   └──────── 每日回填(老闆 10 秒選擇題)———— leads ledger(data/leads/)
```

1. **渠道碼規範**(基礎設施已存在:go/line.html 帶 source 參數+GA4 事件):
   ig-bio / ig-story / fb-post / yt / poster-front / poster-dm / gbp(商家檔案)/ site-faq / ad-a1…
   任何新渠道上線前必須先領碼,無碼不上線。
2. **leads ledger**:`data/leads/YYYY-MM.json`——{date, source_clicks(GA4自動), inquiries(老闆回填), quoted, won, revenue_est}。
3. **唯一必要的老闆輸入(誠實聲明)**:訂單發生在老闆的 LINE 裡,系統看不見。每日 22:50 回報附一題選擇題:「今天 LINE 詢問幾件/成交幾件」——10 秒,這不是行銷人工,是營業數據回填。其餘一切照零人工。
4. **LINE 官方帳號一次性設定**(需老闆 5 分鐘,列「一次性」非每日):自動回應選單(價目表圖/收送說明/儲值金)+ 歡迎訊息。設定文案我全備好。
