# 私享家：從日更內容走到可重複交付的 SEO 服務

版本：2026-09-22 R2／W5。指定 Pro「儲存庫安全掃描摘要」已完成兩輪討論，給 `GO_W5_ZERO_PUBLIC_INTEGRATION`；正式發布維持未核准。本文件是完整規劃與第一個實作切片，不代表 90 天內容已全部做好。

## 要交付的商品

每天累積一篇能回答顧客具體問題的官網母文章，配合真正有吸引力的圖片／影片，再由同一份已核准內容衍生各平台版本。閱讀者可從搜尋進入文章、看懂問題、找到對應服務，再以 LINE 傳照片詢問。網站負責累積內容資產；社群負責讓新客看見；LINE 負責承接詢問。詢問與成交的實際資料另外量測，不由點擊數推算。

試點是私享家；成功後交付給第二家店的是同一套來源格式、品牌設定、產製流程、核稿、發布與回看工具，不是複製私享家的地址、LINE 或圖片文字。

## 愛印可以學到什麼

已讀 https://iprinter.com.tw/daily/ 與其中一篇完整文章。可參考的是：每日索引、獨立正文、直答問題、內連至既有服務，以及文章與社群版本之間的關係。愛印目前頁面自己區分已公開與待驗證內容，後者不放進 sitemap。不能直接複製文章、照片，也不能由它有 daily 頁推定它的搜尋或營收成效。

私享家公開首頁與 sitemap 可讀，但本輪實際 GET `/daily/` 是 404。既有 `generatePublicSite.ts` 已有服務頁、文章、canonical、JSON-LD、sitemap 與 AI discovery 輸出；本案補內容流程與索引，沿用那些能力。

Google 官方說明：AI 搜尋功能仍依基礎 SEO，不需要神奇新標籤或特殊 AI 檔案。可抓取、可索引、有用內容只是參與條件，不保證收錄、排名或 AI 引用。

## 公開網站的樣子

1. `/daily/`：以圖片、日期、問題與摘要呈現真正公開的洗衣筆記；可按主題閱讀。未核稿、未到日期、撤回文章均不可出現。
2. `/posts/YYYY-MM-DD-descriptive-slug.html`：唯一正文 URL。不得另外複製同文到 `/daily/...`。含摘要、直接答案、4–6 個有實際資訊的段落、必要 FAQ、4 張符合品牌品質的圖片、對應服務入口與單一 LINE CTA。
3. 主題入口：先指向現有洗衣價目、鞋包、白鞋、布品收納、台中收送、企業大量送洗頁；只有缺少既有入口且有足夠文章時才新建 cluster。不要同一意圖再造第二個 hub。
4. 網站選單與服務頁：加入日更入口及相關文章；最終須在真部署的網站回讀。只在本機產生 HTML 尚未完成這一步。
5. 網站、社群各自留發布證據；FB／IG 發布不會替網站核准，網站核准也不會自動允許社群真發。

## 每日怎麼做，不再只有計畫表

前置保留 D+3：前一日整理真問題與資料，母稿完成後產製四圖，逐張做文字／材質／構圖检查，再核稿。當日只處理已核准與到期版本；發布後按目的平台回讀。每天保留退稿原因，下批調整。週回看只比較相同 property、日期窗、filter 與事件定義。

P4 兩個社群時段繼續照原契約走。官網一篇母文可以衍生不同問題角度，但不能為湊時段機械複製同一則。影片作獨立製作單位：圖像首幀→Hermes Grok 訂閱原生動態→逐鏡語意與視覺→聲音與字幕→核稿。沒有通過完整影片驗收時，影片維持未完成；若採四圖替代，四圖須單獨符合當日已授權契約。

圖片／影片產量、訂閱與人力成本要依真實製作批次計算。採每日兩組四圖就意味 30 天 240 張、90 天 720 張的製作上限需求；不能拿 24 張成果說整季可交付，更不能為省事用 SVG 填滿。商品報價前需量測每批耗時、退稿率、實際訂閱／平台成本。

## 資料與權限

- Obsidian 放私有母稿、待確認事實、客戶核稿問題、計畫與進度；不放憑證、客人資料或未授權照片。
- P4 保留素材與社群來源正本。顯式 assetId→contentId→SHA；不靠最新檔名猜配對。
- 網站 repo 放 schema、registry、renderer、tests、計畫及符合匯入條件的公開來源。私有稿在 repo 外；preview 在 `output` 或專案外，永不進 `docs`。
- WebsiteApproval 綁文章、圖片、影片、canonical、日期、CTA 與整份門市設定 hash。修改其中任何一項，核准失效。
- PublicationJournal 是首次公開日期與 canonical 的唯一來源；本輪僅 dry-run 讀取合成 journal，尚未開通真 release 寫入。不得把 build 時間填成發布時間。
- 私有核稿 noindex 只是備援，真正的隔離是檔案不在公開樹；不能把私稿丟上 GitHub Pages 再靠 robots.txt 保密。

## 驗收，不靠自述
