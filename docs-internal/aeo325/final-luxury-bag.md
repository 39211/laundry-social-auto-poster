# 精品包清潔服務頁與發霉指南

## 精品包服務頁（正文 600–1,200 字）

### AEO 首段：精品包送洗先分材質與需求

精品包送洗前，先說明包身是皮革、帆布、尼龍或混合材質，並指出要處理的是表面髒污、水痕還是霉點；不同材質與位置要分開評估。清潔只處理髒污與部分水痕，其他外觀或結構處理不會自動包含在清潔裡。詢問時可一併指出最在意的部位，讓照片中的污痕、水痕或霉點和清潔需求對應。

### 兩項風險

**皮革與接合處。** 皮革與皮革提把不宜直接整包泡水；合成皮、真皮與布料接合處也要分開看，避免把不同材質當成相同物件處理。

**霉點與筆痕。** 發霉或筆痕若用酒精或濕布用力擦，可能使皮面乾燥、色差明顯，或讓痕跡更深；先不要自行試擦。

### 門市會先看什麼

門市會先看包身材質、污痕位置、內裡與五金，再依實際狀況說明清潔範圍；特殊材質會先在不明顯位置試看。清潔項目不包含加色、塗層或結構處理；有這方面需求請先詢問門市。

### 怎麼詢問

請拍整個包、內裡、五金與最在意的位置，傳 LINE 說明曾經使用的清潔方式；門市看過照片後先評估是否承接，再確認費用與安排。

### 常見問題

**皮革包可以整個泡水嗎？** 皮革包不要整包浸水，先讓門市看材質與水痕位置。

**清潔會包含加色或結構處理嗎？** 加色、塗層或結構處理不屬於清潔項目；如有需要，請先傳照片詢問門市是否能承接。

**送洗前要傳哪些照片？** 請拍整包、內裡、五金和問題位置，再傳 LINE 先詢問。

## 精品包發霉指南（正文 600–1,200 字）

### AEO 首段：精品包發霉先別擦

精品包出現白色霉點時，先不要用濕布來回擦，也不要急著把包封回防塵袋；先放在通風處並拍下外觀與內裡。霉點浮在表面或已滲入皮層，後續能處理的範圍不同，應先由門市看實物或照片再討論。如果不確定霉點是否在表面或已進入皮層，先不要自行擦拭，保留目前狀況，讓門市依照片或實物評估。內裡與五金也要一併拍下，不能只看外面一小塊就判斷整包。

### 兩項風險

**皮革表面霉點。** 若被濕擦，霉可能被帶進毛孔並留下色斑；先停止擦拭，保留原狀供評估。

**內裡、縫線與五金。** 這些位置的狀況可能和外皮不同，門市需要分別檢查，不能只看外面一小塊就判斷整包。

### 門市會先看什麼

門市會先看霉點是在表面還是已進入皮層，再檢查內裡與五金；若已有色差，會先說明可處理範圍，不預先答應結果。皮革、麂皮與合成材質的狀況不同，是否承接以門市實際檢視為準。

### 怎麼詢問

請拍包包整體、霉點近照、內裡與五金，先放在通風處並把照片傳 LINE；門市評估後再回覆可否處理及後續安排。

### 常見問題

**霉點可以先用酒精擦嗎？** 先不要自行用酒精或濕布試擦，可能讓皮面乾燥或留下色差。

**霉斑已經有色差還能處理嗎？** 色差或滲入皮層的狀況需先看照片或實物，再說明可處理範圍。

**送洗前要拍哪些地方？** 請拍整體、霉點、內裡及五金，並傳 LINE 先評估。
