# Task B2-2: attribution_service.py for the shop PC LINE webhook (Python 3.11, stdlib only)

You are a senior Python engineer writing production code for a small laundry shop's LINE bot that runs on a Windows 10 shop PC with **Python 3.11 embedded, standard library only** (no pip). Output complete files. Do not ask questions; state assumptions at the end.

## Goal
Implement the "inquiry event ledger" part of the attribution design below (sections 2.2, 3, 4 of the design doc are authoritative): when a customer sends a LINE message that contains a public source code like `SXJ-261030-S1`, record a minimal, privacy-safe event to a local append-only JSONL so an offline job can later count "inquiries per content source" and match them against POS intake. Nothing here contacts LINE, the POS, or the network. No replies are changed.
