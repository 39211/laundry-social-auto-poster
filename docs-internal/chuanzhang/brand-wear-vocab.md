## 通用禁止／安全改寫對照

| 禁止（商標／圖樣） | 安全改寫（材質／工法） |
|--------------------|------------------------|
| monogram canvas print, interlocking initials | `coated cotton canvas, fine plain weave, biscuit-tan ground` |
| interlocking C / double-C hardware logos | `turn-lock clasp, embossed round medallion hardware (blank face)` |
| H-stitch padlock motifs, brand stamps | `saddle stitch, blank leather tag shape, unbranded lock form` |
| GG canvas, webbing stripe trademarks | `smooth calf + plain cotton web strap, no pattern` |
| triangular metal logo plaque | `minimalist nylon body, blank metal plaque or no plaque` |
| signature check / tartan lining trademarks | `tone-on-tone twill lining, solid honey gabardine only` |
| swoosh, 3-stripes, star-chevron, N logo | `clean panel lines only—no side marks, no heel logos` |
| brand deboss on sole or heel tab text | `blank heel tab, unbranded outsole texture` |

## 使用備註（給生成流程）

1. **每物件最多挑 2–3 條材質 + 1–2 條磨損**，避免 prompt 過載互相打架。  
2. **磨損要點位置**（handle tops、toe box、collar opening…）比「old / dirty」更穩、更像真實攝影。  
3. 結尾固定加：`no logos, no brand monograms, no readable text, no trademarks`。  
4. 洗衣／送洗情境可再疊：`before-cleaning condition`、`subtle soil only`、`honest pre-owned wear, not destroyed`。
