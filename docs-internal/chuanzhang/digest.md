## 2. 可移植提示詞技法清單（逐條 + 出處）

### A. 結構與門禁

1. **先確認再寫，禁止「先出一版」** — 資產／位置／時間劃分未確認不寫提示詞。`chuanzhang-fenjing/SKILL.md`、`PROMPT_TIMING.md`
2. **每條視頻提示詞 ≤15 秒；15 是上限不是目標** — `PROMPT_TIMING.md`、`fenjing-biaoqing/SKILL.md`
3. **能合併就合併**：同角色＋同地點＋同情緒＋同攝影邏輯 → 一條；勿因換鏡頭就拆條。`PROMPT_DENSITY.md`
4. **1–3 秒只給閃現／道具插入／轉場**，禁止連續堆短條。`PROMPT_TIMING.md`
5. **固定開頭**：`不要出現BGM，不要出現字幕`（在句柄與風格之前）。`PROMPT_PATTERNS.md`
6. **風格四段前置**（句柄前）：`【全局畫質】【人物材質】【燈光與風格】【核心特效】`。`STYLE_BLOCK.md`、`PROMPT_PATTERNS.md`
7. **鏡頭固定字段序**：`畫面動作概述 → 畫面構圖 → 機位 → 動作 →（表情）→ 音效`。`PROMPT_PATTERNS.md`、`fenjing-biaoqing/SKILL.md`
8. **無故事板時完全省略故事板欄**，禁寫「本條不使用故事板」。`PROMPT_PATTERNS.md`
9. **不固定收尾** `15秒。21:9。` — 時長放 metadata／鏡頭標題。`STYLE_BLOCK.md`、`PROMPT_TIMING.md`
10. **可複製正文 ≤2200 中文字**；超限先刪重複形容與非關鍵防錯。`PROMPT_PATTERNS.md`

### B. 空間、道具、手

11. **關鍵道具落表面／被拿取 → 先俯視調度**（米制距離、前後左右、遮擋、眼線）。`SPATIAL_BLOCKING.md`
12. **接觸必須寫清**：誰左誰右、誰前景、左右手歸屬、接觸點、接觸陰影與重量。`portrait-planning.md`、`SPATIAL_BLOCKING.md`
13. **防漂浮道具**：`必須有接觸陰影和重量`；`禁漂浮道具`。`PROMPT_PATTERNS.md`、`STYLE_BLOCK.md`
14. **插入鏡頭鎖焦**：`焦平面從第一幀到最後一幀嚴格鎖定在[物體]上——絕對禁止焦點漂移`。`CAMERA_EMOTION.md`、`PROMPT_PATTERNS.md`
15. **道具句柄寫尺寸、材質、文字、擺放狀態**；人物句柄寫當前狀態（濕／乾／污）。`PROMPT_PATTERNS.md`

### C. 構圖與攝影語言

16. **構圖用區域語言**：左／中／右三分之一、前中後景、負空間、遮擋、接觸點；百分比僅輔助。`PROMPT_PATTERNS.md`
17. **運鏡綁情緒節拍，完成後立刻停**。`CAMERA_EMOTION.md`、`performance-camera-language.md`
18. **禁變焦，寫物理推進／拉遠／橫移**；手持必有呼吸微動。`CAMERA_EMOTION.md`
19. **焦段＝可見效果**（例：`85mm portrait lens look, natural facial proportions, clean background separation`）。`photography-brief.md`
20. **景深寫「背景還能認多少」**，預設 `f/2.8 feel, face/object sharp, background still recognizable`。`photography-brief.md`、`variables-and-texture.md`
21. **道具特寫模板**：50/85mm、F1.4、鎖物體、總位移僅 10–15cm。`CAMERA_EMOTION.md`
22. **廣角建立僅 0.3–0.5 秒** 後硬切，禁桶形／魚眼畸變。`CAMERA_EMOTION.md`

### D. 情緒與微表演（可降階到「手＋物件」）

23. **因果鏈先寫**：`trigger → goal → obstacle → protective strategy → subtext`。`chuanzhangbiaoqing/SKILL.md`
24. **三軸**：內壓／外放／自控 1–5，數字必須翻成可見動作。`performance-recipes.md`
25. **通道錯峰**：眼 → 眼瞼／眉 → 呼吸 → 嘴角 → 下頜 → 頭 → 肩 → **手** → 聲；禁整臉同時最大。`chuanzhangbiaoqing/SKILL.md`、`fenjing-biaoqing/SKILL.md`
26. **禁止泛情緒詞**；拆成肌肉、呼吸、皮膚、姿態、時間。`MICRO_BEATS.md`
27. **震驚／凍結**：身體凍 0.3–0.5 秒 → 瞳孔放大 → 延遲鼻吸氣。`MICRO_BEATS.md`
28. **情緒弧編號** ①開始→②觸發→…→結尾殘留。`MICRO_BEATS.md`、`performance-recipes.md`
29. **無人鏡表情欄不刪**：用道具受力、畫外呼吸、攝影機停寫情緒。`fenjing-biaoqing/SKILL.md`
30. **靜幀凍結「onset 之後或克制頂點」**，留前一刻證據（唇剛分開、濕意剛積）。`performance-recipes.md`

### E. 真實感與材質

31. **寫實＝落到可見部位**：毛孔、飛絲、布料褶、光學散景、高光 roll-off、輕微不對稱。`variables-and-texture.md`、`photography-brief.md`
32. **弱詞升級**：高級感／電影感／膠片感 → 用途＋一鏡頭＋一光＋一色調錨＋具體材質。`photography-brief.md`
33. **一用途、一氣質、一構圖、一焦段、一景深、一光、一色調**；材質只挑 3–5 項。`variables-and-texture.md`
34. **【核心特效】無超現實時寫物理機制**：水霧、塵、纖維、污漬邊界、液體流動。`STYLE_BLOCK.md`
35. **【人物材質】不重複身份服裝劇情**，只寫皮膚／受力／濕乾。`STYLE_BLOCK.md`

### F. 敘事與寫作鐵律（短片層）

36. **只寫可拍可聽**；禁心理描寫、括號暗示、解釋性台詞。`creation-engine.md`
37. **開場鉤子**：前 5 秒建規則或強好奇（概念超短片）。`creation-engine.md`
38. **戲劇動作**＝目標＋阻礙＋結果；無此則不是戲。`creation-engine.md`
39. **雙軌節奏**：情節鬆／中／緊 × 情感輕／中／重，允許錯位。`creation-engine.md`
40. **靜圖七段**：`[Subject+Action]+[Location]+[Composition]+[Lighting]+[Style]+[Camera/Lens]+[Color]`。`tuxiangtishici/SKILL.md`
41. **主體＋動作打頭**，正述「應出現什麼」非堆排除。`tuxiangtishici/SKILL.md`
42. **音效對可見聲源**；三層＝環境／Foley／表演（呼吸、布料、紙）。`full-video-framework.md`
43. **時長由節拍反推**，再選最短可讀時長。`full-video-framework.md`、`chuanzhangbiaoqing/SKILL.md`
44. **防錯分級** `⚠️` / `⚠️⚠️⚠️`（身份漂移、左右顛倒、多加鏡頭、焦點漂移）。`PROMPT_PATTERNS.md`
45. **抓拍語**：「動作像正在發生，不是擺完再拍；笑容正在展開或剛收住」。`portrait-planning.md`

## 3. 物件攝影最有價值 20 條提示詞片段

直接貼進鞋／包／衣／寢具＋手入鏡提示詞（可微調材質）。

1. **鎖焦道具**  
`⚠️焦平面從第一幀到最後一幀嚴格鎖定在[皮鞋／包角／衣領污漬]上——絕對禁止焦點漂移、禁止自動跳焦、禁止中途換焦。`  
← `CAMERA_EMOTION.md` / `PROMPT_PATTERNS.md`

2. **道具插入機位**  
`機位：50mm或85mm大光圈定焦，F1.4極淺景深。畫面中只有[物體]絕對清晰銳利，其他元素全部強烈散焦為模糊色塊。整個X秒內攝影機總位移僅約10-15厘米，速度慢到幾乎察覺不到。禁變焦，禁突然推拉。`  
← `CAMERA_EMOTION.md`

3. **接觸與重量**  
`[物體]必須有真實接觸陰影與重量感；禁止漂浮道具、禁止懸空無支撐。`  
← `PROMPT_PATTERNS.md` / `STYLE_BLOCK.md`

4. **手歸屬（解剖）**  
`右手拇指與食指捏住[鞋後跟／包拉鍊頭]，左手穩定[鞋身／包底]；左右手歸屬清楚，手指數量正確，禁止手指融合、多餘手指、手臂穿插。`  
← `portrait-planning.md`

5. **左右前後鎖死**  
`[物體]位於畫面中央偏下，手從畫面右側伸入；物體在手的前方，桌面在物體下方，背景在手後方；禁止左右顛倒、前後錯位。`  
← `SPATIAL_BLOCKING.md` / `PROMPT_PATTERNS.md`

6. **畫面構圖骨架**  
`畫面構圖：主體位於畫面中央偏下，佔畫面高度約35–45%；前景為指尖接觸點，中景為物體主體，遠景為柔和虛化的工作台面負空間。`  
← `PROMPT_PATTERNS.md`

7. **構圖百分比錨（可選）**  
`物體中心約在x=50%、y=58%；接觸點靠近y=72%；手指進入畫面從右側約x=78%。`  
← `PROMPT_PATTERNS.md`

8. **真實感材質（布／皮）**  
`服裝／皮面有真實布料或皮革紋理、自然褶皺、接縫與磨損邊緣；保留污漬邊界與纖維走向，不要塑料感表面。`  
← `variables-and-texture.md`

9. **皮膚與受力（手）**  
`手背與指節保留自然皮膚紋理與輕微毛孔；捏緊時指節發白、指甲邊緣有輕微壓力變形；不要塑料手、不要過度磨皮。`  
← `STYLE_BLOCK.md` / `variables-and-texture.md`

10. **全局畫質（實拍洗衣）**  
`【全局畫質】真實電影／產品紀實攝影質感，高解析、大畫幅、實拍感，畫面必須符合真實物理；不要三維渲染感，不要遊戲引擎質感，不要動畫或插畫風格。`  
← `STYLE_BLOCK.md`

11. **燈光（工作台）**  
`【燈光與風格】主光來自左側柔和窗光或工作台灯，方向明確；物體表面有清晰高光過渡與柔和接觸陰影；膚色與皮料色不過度美化；低飽和寫實，接近紀錄片自然色。`  
← `STYLE_BLOCK.md` / `photography-brief.md`

12. **核心物理機制（污漬／水）**  
`【核心特效】[咖啡漬／泥點／油痕]邊界清晰、滲透層次可見；擦拭時水分在纖維上真實擴散，帶輕微反光與殘留濕痕，禁止魔法式瞬間變乾淨。`  
← `STYLE_BLOCK.md`（改寫為物理機制）

13. **景深預設（物件＋可識背景）**  
`f/2.8 feel, moderate shallow depth of field, [鞋面／包角／領口] sharp, background still recognizable as clean work surface`  
← `photography-brief.md`

14. **鏡頭感（產品＋手）**  
`50mm natural perspective, balanced proportions, realistic everyday distance` 或 `85mm close product look, clean separation, optical bokeh not artificial blur`  
← `photography-brief.md` / `variables-and-texture.md`

15. **抓拍非擺拍**  
`動作像正在發生，而不是已經完成後靜止擺拍；允許手指剛碰到、剛翻開、剛抬起的一瞬間；允許輕微不對稱與真實停頓。`  
← `portrait-planning.md`

16. **微表演（檢查／猶豫）**  
`視線先停在污漬邊緣；0.4秒身體凍結後出現一次延遲鼻吸氣；拇指壓彎布邊／壓緊鞋面；肩膀輕微上提；下頜收緊但不誇張鬼臉。`  
← `fenjing-biaoqing/SKILL.md` 表情範例＋`MICRO_BEATS.md`

17. **震驚凍結（發現污漬）**  
`鏡頭開始瞬間身體凍結0.3-0.5秒；凍結瞬間瞳孔放大；嘴唇微張但無聲；凍結結束後一次延遲急促鼻吸氣；眼睛鎖定[污漬]，不眨眼、不移開。`  
← `MICRO_BEATS.md`

18. **克制專業（師傅判斷）**  
`呼吸平穩均勻；手指和手臂放鬆但精準；緩慢均勻眨眼；下頜微微抬起；動作節奏像專業檢查而非慌張翻找。`  
← `MICRO_BEATS.md`「控制／冷靜」改寫

19. **音效三層（物件）**  
`音效：布料／皮革摩擦細微聲、指尖壓過接縫的輕響、工作台低頻環境嗡鳴；禁止無關BGM與字幕。`  
← `full-video-framework.md` + 固定開頭規則

20. **防錯打包（鞋包衣寢具）**  
`⚠️禁身份漂移與多餘手。⚠️⚠️⚠️禁漂浮道具、禁左右顛倒、禁污漬位置漂移、禁無接觸陰影、禁鏡頭擅自增加。`  
← `PROMPT_PATTERNS.md`

## 4. 分鏡＋情緒融合 → 15 秒前／中／後三幕

### 總原則（直接可執行）

- **整支 15 秒＝1 條視頻提示詞**（同一地點、同一雙手＋同一物件、情緒連續）。勿拆 3 條各 5 秒，除非地點硬切。出處：`PROMPT_DENSITY.md`、`PROMPT_TIMING.md`
- 每鏡字段：`畫面動作概述／畫面構圖／機位／動作／表情／音效`。出處：`fenjing-biaoqing/SKILL.md`
- 情緒用「發現問題→檢查／處理→結果殘留」代替崩潰演技；三軸偏：**內壓中高、外放低、自控高**（諮詢式，不戲劇化）。出處：`performance-recipes.md` + 私享家文案調性

### 三幕時間分配（建議 4 + 6 + 5）

| 幕 | 秒 | 節拍功能 | 景別／機位 | 情緒階段 | 攝影機 |
|---|---|---|---|---|---|
| **前** | 0.0–4.0 | 觸發：物件＋問題進畫 | 0.5s 可選廣角閃現 → 主 3.5s 物件中近景 | baseline → **recognition** | 先靜；識別後極慢推進 ≤10cm |
| **中** | 4.0–10.0 | 阻礙＋策略：手檢查／翻邊／對光 | 85mm 細節＋手部近景可內部切 1 刀 | **resistance → leakage** | 手持極弱呼吸；焦鎖污漬／材質 |
| **後** | 10.0–15.0 | 頂點＋餘波：判斷完成／收勢（非魔法變乾淨） | 半身或物件＋手定格 | **apex → residue** | 推進停住；可 0.3s 俯拍凍結收 |

### 情緒因果（每支片填一次，再寫進各鏡 `表情：`）

```text
觸發：發現[泥點／咖啡漬／皺褶／異味痕跡]
目標：在客人面前判斷能否處理、從哪裡下手
阻礙：材質敏感／污漬已滲入／結構怕扯壞
保護策略：放慢、對光、輕觸、不硬搓
潛台詞：這不是「髒到沒救」，而是「要對的做法」
```

### 逐鏡寫法模板（複製即用）

```text

【燈光與風格】左側窗光／工作台灯…低飽和寫實
【核心特效】污漬邊界與濕痕物理機制…（無特效就寫材質微觀）
@image1（雙手＋當日制服袖口狀態）

【鏡頭1｜0.0—4.0秒】  // 前幕
畫面動作概述：問題物件首次進畫，問題點可讀。

【鏡頭2｜4.0—10.0秒】  // 中幕
畫面動作概述：雙手檢查材質與污漬邊界（唯一主動作）。
畫面構圖：污漬佔畫面中心；拇指接觸點清晰；背景工作台可識但虛。
機位：85mm，F1.4–2.8感，焦平面鎖污漬；手持呼吸微動。
動作：①指腹沿污漬邊界輕觸 ②翻邊／對光 ③停在判斷點（不表演搓洗奇蹟）。
表情：抵抗＝想快擦掉卻壓住；生理泄漏＝下頜微緊、一次吞咽、拇指壓彎皮面／布邊；外放升到2/5。
音效：皮革／布料摩擦、指尖壓縫輕響。

【鏡頭3｜10.0—15.0秒】  // 後幕
畫面動作概述：檢查完成的定格勢；問題仍可讀、態度已定（交給專業）。
畫面構圖：物件穩定居中；手退半寸或輕托；負空間留給品牌安全感。
機位：50mm半身／中近景；運動停止；可選0.3秒正上方俯拍凍結收尾。
動作：手勢從「檢查」收到「托穩」；不再二次亂摸。
表情：頂點＝一次短促點頭式下頜放鬆；餘波＝視線從污漬移到整體輪廓，呼吸放慢。外放回1/5，自控回5/5。禁止淚水、禁止誇張崩潰。
音效：布料落穩、環境低頻延續；收在安靜而非音樂高潮。
```

### 與私享家既有腳本尺規對齊

既有：`1 秒見物 → 一衝突 → 一動作 → 一回報 → 一 CTA`。  
船長法補的是：**每一步的可見肌肉／手／焦平面／音效**，以及 **15 秒內部三鏡頭不拆條**。CTA 放畫外字幕或剪輯層，提示詞內維持 `不要出現字幕`。
