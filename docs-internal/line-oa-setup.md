## 2. 自動回應訊息 (自動回應 > 關鍵字回應)

依序新增以下 4 組關鍵字：

### 關鍵字 A：【同行】（同業夥伴專用分流）
* **關鍵字**：`同行`、`同業`、`交流`、`示範店`
* **回應內容**：
  ```
  您好！我是私享家洗衣店的老闆。很高興能跟洗衣同業夥伴交流！

  我們店裡這套「示範店引流展示系統」，是我們在西屯青海路門市與台中全區收送真實運作的模式：
  1. Google 搜尋引流（在地關鍵字著陸頁 + 價目表透明化）
  2. 台中全區免費到府收送的路線與排程規劃
  3. 實體合作店家包裹卡與在地宣傳小試驗
  4. 真實成本與成效復盤（零廣告預算自然流量、實際工時與訂單）

  如果您想了解如何應用在您的店裡，或是想探討「跨區收送相互轉介」的合作可能，請直接留下：
  1. 您的店名與所在縣市/行政區：
  2. 您目前主要想加強門市散客、還是到府收送：

  我忙完門市洗護工作後會親自回覆您！
  ```

### 關鍵字 B：【價格】
* **關鍵字**：`價格`、`多少錢`、`價目`、`價錢`
* **回應內容**：
  ```
  各品項公開水洗參考價：運動鞋 $250 起、皮鞋 $400、雙人棉被 $500、名牌包 $1500 起、皮衣 $1200。
  乾洗柔洗另計，發霉特殊污漬以實際檢視為準。
  拍照傳給我們，師傅直接幫你看狀況報準確價！
  ```

### 關鍵字 C：【收送】
* **關鍵字**：`收送`、`到府收送`、`收件`、`外送`
* **回應內容**：
  ```
  台中市全區免費到府收送！一件也收、沒有最低消費門檻。
  收送本身免運費，清潔洗護費用另計。
  請直接跟我們說您的「收件地址」與「方便時段」，或是交由大樓管理室代收也可以喔！
  ```

### 關鍵字 D：【儲值】
* **關鍵字**：`儲值`、`優惠`、`折扣`
* **回應內容**：
  ```
  私享家門市儲值優惠：
  💰 儲值滿 1,000 送 100
  💰 儲值滿 3,000 送 400
  💰 儲值滿 6,000 送 1,000
  到店送洗或司機到府收件時都能直接辦理！
  ```

## 3. 圖文選單 (選單 > 建立)

建議三格版面：
1. **【透明價目表】**：開啟連結 `https://sixiangjialaundry.com/services/taichung-laundry-price-list.html`
2. **【免費到府收送】**：設定文字觸發「收送」
3. **【老闆示範店展示】**：開啟連結 `https://sixiangjialaundry.com/guides/laundry-partner-showcase.html?source=line-menu-peer`

---

## 4. 效益與防護

* **一般送洗客**：進入後第一眼看懂拍照報價、門市位置與免費收送，正常傳照片詢價。
* **同業夥伴**：回傳「同行」獲得老闆親自交流的專業引導，不干擾門市店員日常洗護。
* **精準追蹤**：網站透過 `?source=peer-showcase` 等渠道碼精準歸因，GA4 可即時洞察流量與點擊趨勢。
