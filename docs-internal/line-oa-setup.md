# LINE 官方帳號 5 分鐘設定包(一次性)

到 LINE Official Account Manager(manager.line.biz)→ 選你的帳號:

## 1. 歡迎訊息(自動回應 > 加入好友的歡迎訊息)
貼上:
---
歡迎加入私享家洗衣店!
拍照傳給我們,師傅先幫你看狀況再報價 👍
📍 西屯青海路二段365號(至善國中對面)
🚚 台中市全區免費收送
💰 價目表點下方選單
---

## 2. 自動回應訊息(關鍵字)
- 關鍵字「價格」「多少錢」→ 回:各品項公開價目:運動鞋$250起、皮鞋$400、雙人棉被$500、名牌包$1500起(水洗價,乾洗另計)。拍照給我們,師傅直接報準確價!
- 關鍵字「收送」→ 回:台中市全區免費到府收送!跟我們說地址和方便時段,收送不加價,清潔費另計。
- 關鍵字「儲值」→ 回:儲值優惠:滿1000送100/儲3000送400/儲6000送1000,到店或收件時都能辦。

## 3. 圖文選單(選單 > 建立)
三格:【價目表】(放價目圖)|【免費收送】(觸發收送回應)|【儲值優惠】(觸發儲值回應)

設定完跟 Claude 說一聲即可。之後客人半夜傳訊息也有第一時間回應,不漏單。
