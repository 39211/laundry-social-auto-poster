# 海報規格正本 — 字高由可讀距離推導,不由眼睛挑

> 前三版被退,共同死因是**我用眼睛決定字級**。這份把它換成公式。
> 每一條都附可查證來源;查不到本地實測的,明寫「找不到」,不編數字。

## 一、字高公式(唯一硬規則)

業界通用:**每 10 英尺閱讀距離需要 1 英寸大寫字高**。
來源:[Signs.com](https://www.signs.com/blog/signage-101-letter-height-visibility/)、
[Pannier Graphics](https://www.panniergraphics.com/blog/letter-height-visibility-chart-for-outdoor-sign-readability)

換算公制:**字高(mm) = 閱讀距離(m) × 8.33**

門口 A4 海報的距離分配與推導結果:

| 元素 | 該在幾公尺外讀到 | 字高 |
|---|---|---|
| 主標 | 3.0m(走過的人) | **25mm** |
| 優惠(現在來的理由) | 2.5m | **21mm** |
| 副標 | 2.0m(停下腳步) | **17mm** |
| 電話 | 1.5m | **12.5mm** |
| 地址 | 1.2m | **10mm** |
| QR 說明・營業時間 | 0.8m(站到面前) | **6.7mm** |

**副標必須是主標的 0.55–0.7 倍**(Grok 研究的台灣門市規格卡)。
25 × 0.67 = 16.7mm ✓

## 二、版面

- **A4 直式 216×303mm(含 3mm 出血)**,安全邊 ≥10mm
- 留白目標約 30%
- 顏色:主色 60% / 輔色 30% / **強調色 10%,且只用在 CTA 或一個數字**
- 字體:**全橫排、粗黑體**(明體遠距易糊);中文行距 1.3–1.5 倍
- 資訊層級 **3 層**,元素順序:**鉤子 → 對象 → 利益 → 圖 → CTA → 店名/電話/LINE**
- **一張海報只推一個行動。** 完整價目放櫃檯,不放門口

## 三、QR

- 門口海報 **邊長 ≥25–30mm**,周圍留白 ≥5mm;櫃檯立牌 ≥40mm
- **不要只印 LINE ID 文字**——手打 ID 的放棄率遠高於掃碼
- 最佳組合:大 QR + 一句利益句 + 小字 ID 備援
- 來源:[LINE for Business 台灣](https://tw.linebiz.com/faq/Marketing/69/)

## 四、實作規則(寫進渲染器,不靠記憶)

`output/print/` 的渲染腳本必須:

1. 字高由 `距離 × 8.33` 產生,**不得手寫字級**
2. 斷言副標/主標比例在 0.5–0.75
3. `put()` 回傳文字實際底部(中文約字級 ×1.28),後續元素必須在它之下
4. 存檔前斷言底部 ≤ 頁高 − 10mm

第 3 條是 v4 與 v5 各犯一次的坑:只算「區塊高度」不算「文字實際佔高」,
文字就會壓到下一個元素身上,而且**不會報錯**。
