# Google 評論邀請流程(⑧,老闆五題第 5 題)

給老闆的固定流程,搭配 `data/gbp-reviews.json` 的週度基準追蹤。不做逐客資料庫——
這個 repo 是公開的 GitHub repo,不放客人姓名/電話;有沒有問過、有沒有留,
就看您自己 LINE 對話紀錄即可,不用另外記表。

## 什麼時候問(3 個自然時機)

1. **客人當面或在 LINE 打字稱讚時**——轉換率最高的時機,當下用「範本 2」。
2. **客人來店取件、東西處理得不錯、沒有特別抱怨**——當下或隔天用「範本 1」。
3. **客人有客訴或東西沒處理好**——**不要問**,先把問題解決,不要在这个時候邀評。

**只問一次。** 問過之後不管有沒有留,不要對同一位客人追問第二次——騷擾式催評比沒有評論更傷。

## 範本 1(標準版)

> [客人稱呼]您好,這次的[品項]處理好囉,麻煩您確認一下有沒有滿意的地方 🙏
> 如果這次服務您滿意,方便的話幫我們在 Google 留顆星星嗎?對我們這種小店真的幫助很大 🌟
> Google 搜尋「私享家洗衣店」,點評論分數的地方就可以留了,大概 10 秒鐘~謝謝您!

## 範本 2(高滿意時刻版——客人主動稱讚時用)

> 謝謝您這麼說,真的很開心聽到!方便的話能不能請您把剛剛說的這句話,順手也留到 Google 評論嗎?
> 搜尋「私享家洗衣店」就找得到,這對我們真的很重要 🙏

## 可選:把「搜尋」換成一鍵連結

Google 商家檔案本身有「獲得更多評論」功能,會產生一個一鍵連結(比叫客人自己搜尋更順手)。
取得方式:手機 Google Maps app →您的商家檔案→「評論」→「獲得更多評論」/「分享評論表單」,
複製那個連結傳給我,我把上面兩則範本裡的「Google 搜尋『私享家洗衣店』」換成那個連結。
**這個連結我這邊技術上抓不到**(商家檔案管理工具的分享對話框在這個瀏覽器環境點不開),
需要您自己用手機點一次,10 秒鐘,不急。

## 追蹤方式

不建立客戶清單。`data/gbp-reviews.json` 的 `weekly[]` 每次我做週優化巡檢時手動查一次
(business.google.com 評論頁,眼睛看,因為 GBP 帳戶管理 API 配額還是 0),
