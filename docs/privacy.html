隱私權政策

私享家洗衣店（西屯門市，以下稱「本店」）重視您的個人資料。這份說明告訴您：本店收集哪些資料、用在哪裡、保存多久，以及您可以怎麼查詢或要求刪除。

一、本店是誰

  • 名稱：私享家洗衣店（西屯門市）
  • 地址：台中市西屯區青海路二段365號（至善國中對面）
  • 電話：04-2452-7411
  • LINE：LINE 0968-327-653

二、收集哪些資料、為什麼收集

什麼時候收集的資料用途
您用 LINE 聯絡本店LINE 顯示名稱、您傳的文字訊息、衣物鞋包的照片回答問題、看照片評估能不能處理與報價、約定收送時間
您送洗或預約收送姓名、電話、收送地址、送洗物品內容與狀況、取件與付款紀錄處理訂單、聯絡取件、收送、處理客訴
您瀏覽本店官網Google Analytics 收集的瀏覽統計（看了哪些頁面、大概地區、使用的裝置與瀏覽器；透過 Cookie）了解哪些內容有人看，改善網站

本店的 LINE 官方帳號有AI 協助的自動回覆：您傳的文字訊息與照片，會交給 AI 服務商處理，用來產生回覆與初步估價，主要是 Google（Gemini），系統忙碌或故障時可能改用 Anthropic（Claude）或 OpenAI。重要的事情（報價、能不能處理、取件時間）仍由本店人員確認。

本店不會販售您的個人資料，也不會用您的資料做與上述無關的事。

三、照片與影片

您傳給本店的衣物照片，只用來評估與處理您的送洗物品。本店在社群平台發佈的影片與圖片，不使用您傳來的照片，也不會出現您的姓名或可以認出您的資訊；若想使用，一定先徵得您同意。

四、保存多久

  • LINE 對話與照片：訂單完成後保留 1 年，供查詢與處理客訴。
  • 訂單資料：保留 5 年。
  • 網站瀏覽統計：Google Analytics 的明細資料最多保存 14 個月。

時間到了會刪除，或改成無法識別個人的統計資料。

五、資料會給誰

原則上只有本店人員使用。以下情況例外：

  • 本店使用的服務商，只在提供服務需要的範圍內處理資料：LINE（訊息）、Google（網站統計、AI 自動回覆）、Anthropic 與 OpenAI（AI 自動回覆的備援）。這些服務商可能在台灣以外的地區處理資料。
  • 收送由本店人員自己處理，不委託外部物流。
  • 法律規定，或司法、警察機關依法要求時。

六、本店的社群發佈工具與 Google／YouTube 資料

本店使用自己架設的發佈工具（Sixiangjia Postiz），把本店自己拍的影片與貼文發到本店的 Facebook、Instagram、YouTube、TikTok 帳號。這個工具：

  • 只連結本店自己的社群帳號，不連結、也不讀取任何顧客的帳號。
  • 透過 YouTube API 服務上傳與管理本店頻道的影片、讀取本店頻道的觀看數據。使用本工具即表示同意 YouTube 服務條款；Google 如何處理資料，請見 Google 隱私權政策。
  • 本工具從 Google API 取得的資料，其使用與傳遞會遵守 Google API 服務使用者資料政策，包括「有限使用」（Limited Use）的規定。
  • 授權可隨時到 Google 帳戶的 第三方連結 頁面撤銷。

七、您的權利

依個人資料保護法，您可以：

  1. 查詢或閱覽您的資料
  2. 要求提供複本
  3. 要求補充或更正
  4. 要求停止收集、處理或利用
  5. 要求刪除

請用 LINE 0968-327-653 或電話 04-2452-7411 聯絡本店。本店確認是您本人後，查詢、閱覽或複本會在 15 天內回覆；補充、更正、停止利用或刪除會在 30 天內處理。如有必要需要延長，會告訴您原因，延長最多一次、同樣天數。刪除的方法也寫在資料刪除說明。

您可以選擇不提供資料，但本店可能就無法替您估價、收送或處理訂單。

八、Cookie

官網使用 Google Analytics 的 Cookie 做瀏覽統計。您可以在瀏覽器設定中封鎖或刪除 Cookie，不影響瀏覽網站。
