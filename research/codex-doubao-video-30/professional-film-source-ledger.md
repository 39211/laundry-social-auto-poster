# 劇本、導演、製片與宣傳片一手來源帳本

檢索日：2026-07-20。用途：只保存會改變私享家製作決策的一手依據。來源欄只描述原頁可支持的範圍；最後一欄是本專案的採用決策或推論，不宣稱為工會、平台或標準對台灣短廣告的強制規則。

| 範圍 | 一手來源 | 來源可支持的主張／適用限制 | 本案採用決策（本地規則或推論） |
|---|---|---|---|
| 劇本 | [AFI](https://www.afi.com/news/what-is-screenwriting-and-what-does-a-screenwriter-do/) | 用角色、結構與可拍行動說故事 | 劇本不混入 prompt、shot list 或尾卡 |
| 角色 | [Sundance Collab](https://collab.sundance.org/catalog/Crafting-Your-Short-Film-Screenplay) | 短片仍要辨識 want 與 need | 夫妻各有明日目的；共同 need 是停止把同一答案套給四件物件 |
| 可見行動 | [BAFTA/BFI Andrew Bovell](https://www.bafta.org/media-centre/press-releases/bafta-bfi-screenwriters-lecture-series-andrew-bovell/) | 這是創作者講座／職涯觀點；頁面以角色所做之事談其劇本方法，不是通用格式規範 | V3 把抽象內在解說改為可見行動；屬本案創意選擇 |
| 改稿權 | [WGA Creative Rights](https://www.wga.org/contracts/know-your-rights/creative-rights-for-writers) | 說明特定 WGA MBA theatrical／long-form TV 情境的改稿與創作權；不直接適用台灣短廣告 | 為避免多人暗改，本案自行規定只有 Screenwriter 修改 screenplay |
| 鎖稿 | [PGA Code of Credits](https://producersguild.org/code-of-credits-feature-films/) | Producer 職責包含監督 final script、schedule、budget；未規定本案 token 簽發者 | 本案自行指定 Creative Producer 簽 `SCRIPT_LOCK` |
| 商業製作 | [AICP Agreement](https://aicp.com/assets/editor/Standard_Commercial_Production_Agreement_1.pdf) §3 | 品牌素材、道具、授權與交付分清 | Logo、CTA、物件、場地、演員、音樂逐項建帳 |
| 導演 | [ScreenSkills Director](https://www.screenskills.com/job-profiles/browse/film-and-tv-drama/development-film-and-tv-drama-job-profiles/director-film-and-tv-drama/) | 將鎖定劇本轉成視聽意圖 | 心理狀態轉成停手、視線與收納 |
| 副導 | [ScreenSkills AD](https://www.screenskills.com/job-profiles/roles/assistant-director/) | 鎖稿後拆解及排程 | 現在只做 previsualization |
| 製片 | [ScreenSkills Line Producer](https://www.screenskills.com/job-profiles/roles/line-producer-film-and-tv-drama/) | 管預算、crew、合約、時間與安全 | 不可自行刪故事，只能提變更單 |
| 攝影 | [ScreenSkills DoP](https://www.screenskills.com/job-profiles/browse/film-and-tv-drama/technical/director-of-photography-dop/) | 光線、構圖、移動服務導演意圖 | 每鏡列材質與手部 kill criteria |
| 美術 | [ScreenSkills Production Designer](https://www.screenskills.com/job-profiles/roles/production-designer-film-and-tv-drama/) | 從劇本建立生活世界 | 同一家庭的餐桌、玄關、客廳必須有可追溯空間關係，不可用三張無關AI背景拼接 |
| 場記 | [ScreenSkills Script Supervisor](https://www.screenskills.com/job-profiles/browse/film-and-tv-drama/technical/script-supervisor-film-and-tv-drama/) | 非順拍素材須有連戲狀態 | 保存工具距離、方向、開合與持手 |

| 聲音 | [ScreenSkills Sound Editor](https://www.screenskills.com/job-profiles/roles/supervising-sound-editor/) | picture lock 後 spotting | 房間聲、Foley、音樂、TTS 分軌 |
