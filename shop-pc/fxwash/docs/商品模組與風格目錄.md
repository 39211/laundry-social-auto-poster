# 洗衣 LINE 商品模組與風格目錄

這份目錄給業務和店主一起選。選完只代表「要做哪些能力」，不代表已經登入 LINE、發布選單或完成手機驗收。

## 建議方案

| 方案 | 適合誰 | 預設模組 |
|---|---|---|
| 基本客服包 starter | 先把 LINE 客服和查件做穩 | 品牌選單、真人感客服、店員接手、查件進度 |
| 成長營運包 growth | 想減少來回打字並接住新客 | starter＋外收送、照片問價、客人自行輸入／掃碼付款 |
| 品牌經營包 pro | 要做會員經營和固定內容 | growth＋集點優惠、LINE 圖文推播內容 |
| 客製模組包 custom | 已有系統或特殊流程 | 依需求逐項選擇，逐項驗收 |

## 模組狀態

| 模組 | 解決的問題 | 目前狀態 | 店家要準備 |
|---|---|---|---|
| 品牌基礎與 LINE 選單 | 客人找不到入口、按鈕不一致 | ready | 店家資料與素材 |
| 真人感客服回覆 | 回覆像機器人、客人不知道下一步 | ready | 常用說法與規則 |
| 店員接手與群組通知 | AI 接不到的問題沒人處理 | ready | 憑證、店員群與接手規則 |
| 查件進度與金額摘要 | 客人一直問好了沒、多少錢 | ready | 唯讀連接器與授權測試 |
| 外收送引導預約 | 老人家不會一次打完資料 | prepared | 範圍、時段、費用、電話 |
| 照片問價與人工複核 | 客人想先知道大概多少 | prepared | 視覺模型、同意、價目、複核 |
| LINE Pay 客人自行輸入／掃碼 | 客人需要付款入口 | ready | 店家 LINE Pay 入口與對帳規則 |
| LINE Pay Online API | 想自動建單、回呼、核帳 | integration_required | 商戶憑證、回呼、正式驗收 |
| 集點卡與優惠券 | 提高回訪和活動轉換 | prepared | 點數、期限、兌換規則 |
| LINE 圖文推播內容包 | 不知道要發什麼、怎麼寫 | prepared | 活動目標、素材、核稿人 |
| FB／IG／YouTube／SEO 加購包 | LINE 之外也要持續曝光 | add_on | 平台帳號、素材與發布權限 |

## 五種風格

| key | 客人感受 | 適合門市 |
|---|---|---|
| `heritage_green_gold` | 安心、講究、有熟店感 | 精品洗衣、重視質感 |
| `warm_cream` | 溫暖、好懂、沒有距離 | 社區、家庭、長輩 |
| `clean_teal` | 快速、清楚、專業 | 連鎖、商辦、高頻查件 |
| `friendly_sun` | 明亮、有人帶著走 | 年輕家庭、學生 |
| `modern_mono` | 俐落、可靠、有品牌感 | 高端、商務、多分店 |

風格會改變色彩、字體、選單版型和回覆語氣。任何價格、服務時間、地址與付款規則都只能從該店提供的資料產生。

## 選擇規則

1. 每家店先選一個方案與一種風格。
2. 需要資料源的模組先標成「待設定」，不得用示範資料當正式結果。
3. `line_pay_qr` 和 `line_pay_online` 不同時開啟；本商品預設是客人自行輸入／掃碼，Online API 要另做整合驗收。
4. 照片問價一定要有告知同意、區間估價但書和人工接手路徑。
5. 選單圖片好看、設定檔驗證通過，都不能取代 LINE 後台回讀與手機逐格測試。
